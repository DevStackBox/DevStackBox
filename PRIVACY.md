# Privacy Policy - DevStackBox

DevStackBox runs on your computer. Your projects and databases stay local.

## Summary

- No telemetry
- No accounts
- No required internet for daily development

## Network use

| When | Destination | Why |
| ---- | ----------- | --- |
| Manual check or enabled automatic update checks | GitHub Releases API | Show latest version |
| You install an update | GitHub release downloads | Download the signed installer |
| You download a PHP version | windows.php.net | Fetch the PHP build you selected |
| Normal use | None | Stack runs offline |

## Data locations

| Data | Location |
| ---- | -------- |
| Web projects | `C:\devstackbox\www` (default install) |
| Config, logs, MySQL data | `%LOCALAPPDATA%\devstackbox\` |
