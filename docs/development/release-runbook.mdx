# v0.1.18 release runbook

Run from the app repository root on Windows. Source preparation is not proof of a published or installer-qualified release. Follow [Release process](./release-process) for acceptance gates.

## Preflight

```powershell
npm ci
npm run check
cargo test --manifest-path src-tauri/Cargo.toml --lib
node scripts/test-apache-overrides.mjs --legacy
node scripts/test-apache-overrides.mjs
.\scripts\test-database-workspace.ps1
```

App version 0.1.18 must match package.json, Cargo.toml and tauri.conf.json. Keep the root package version in package-lock.json and the devstackbox package in Cargo.lock synchronized. Historical dependency versions are not app versions.

## Build and finalize

```powershell
$env:TAURI_SIGNING_PRIVATE_KEY_PATH = "$env:USERPROFILE\.tauri\devstackbox.key"
npm run build:release
npm run finalize-release
node scripts/verify-updater-artifact.mjs
```

Supply the signing-key password through your private environment if required. Never commit or print key material. The build wrapper runs input verification, Tauri build and updater-artifact verification. It does not need MSI cleanup or termination of unrelated processes.

Finalization requires the exact installer bytes and signature. It generates release/notes-v0.1.18.md, both latest.json files, the changelog checksum and packaging metadata. Do not relabel previous hashes or signatures. Tauri updater signatures are separate from Windows Authenticode publisher signing.

## Installer acceptance

Test the actual generated installer using the repository checklist `docs/getting-started/local-install-test.md` and [Testing](./testing). Record results in docs/RELEASE-VALIDATION.md. Verify the real Laravel site on HTTP and HTTPS after upgrading and restarting Apache; synthetic rewrite tests alone do not qualify that site.

## Publish after acceptance

```powershell
gh release create v0.1.18 --verify-tag --title "DevStackBox v0.1.18" --notes-file "release/notes-v0.1.18.md" "src-tauri/target/release/bundle/nsis/DevStackBox_0.1.18_x64-setup.exe" "src-tauri/target/release/bundle/nsis/DevStackBox_0.1.18_x64-setup.exe.sig" "latest.json"
node scripts/finalize-release.mjs --verify-github v0.1.18
```

Create and push the reviewed v0.1.18 tag before the publish command. Stable releases must not be marked prerelease. Verify updates from v0.1.17, then publish the website with its app-doc source pinned to the same release. Keep download URLs, hashes and sizes sourced from the published GitHub assets.
