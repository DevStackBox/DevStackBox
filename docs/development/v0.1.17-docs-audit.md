## Keep / do not sweep

- apache/, mysql/, php/, phpmyadmin/, tools/: bundled or installed runtimes and licenses; not disposable development clutter.
- www/, logs/, user data, config backups, databases and additional PHP branches: may contain active user work or recovery data.
- review-artifacts/\* backup and runtime directories: include preinstall configuration, upgrade backups, private certificates and test profiles. Inspect individually; names alone do not establish disposability.
- release/, latest.json, packaging manifests and src-tauri/target/release/bundle/: preserve exact signed release evidence until archived and verified. Cargo target removal is rebuildable but would also remove these artifacts.
- docs/archive/, docs/RELEASE-VALIDATION.md, docs/LOCAL-HTTPS.md, ADRs, PROJECT-ROADMAP.md, website LAUNCH-MEDIA.md and IMPLEMENTATION-REPORT.md: retain design/validation/media provenance. Historical status is not a claim of current readiness.
- node_modules/: reinstallable, but deleting it is not necessary for repository cleanliness and interrupts local tools.
- Signing keys, certificates and .env files: never include in cleanup batches or publish as documentation.
