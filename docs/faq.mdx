## What is DevStackBox?

DevStackBox is a free XAMPP alternative for Windows. One installer includes Apache, MySQL 8.4 LTS, phpMyAdmin, and PHP 8.3.

## Which PHP versions are included?

**PHP 8.3** ships in the installer. **PHP 8.1, 8.2, 8.4, and 8.5** are available under **Services → PHP → Versions** (download, then switch). PHP 8.5 is the newest supported branch.

## Is DevStackBox free?

Yes. DevStackBox is MIT-licensed open source. There is no paid tier.

## Where does DevStackBox install?

The application installs to `C:\devstackbox` by default (you can choose another path). User data - configs, logs, and MySQL files - is stored in `%LOCALAPPDATA%\devstackbox\`. Web projects use `C:\devstackbox\www` by default.

## Can I move projects from XAMPP?

Yes. Use **Settings → Import from XAMPP** to copy `htdocs` into DevStackBox `www`. Export databases from XAMPP phpMyAdmin and import them in DevStackBox if needed.

## Does DevStackBox collect telemetry?

No. DevStackBox does not collect usage data or phone home. See the [Privacy Policy](/privacy).

## How do I report a bug?

Open a [GitHub Issue](https://github.com/DevStackBox/DevStackBox/issues) or start a [Discussion](https://github.com/DevStackBox/DevStackBox/discussions).

## How do I report a security issue?

Email **hello@devstackbox.com**. Do not open public issues for vulnerabilities. See [Security](/security).

## Can each project use a different PHP version?

Yes, in v0.1.12. Download the runtime in PHP Versions, then select it in project details. Only installed runtimes are offered. This affects website requests; the terminal still uses global PHP. See [Projects, PHP & HTTPS](getting-started/projects).

## Can a trusted HTTPS site return 404?

Yes. A certificate verifies the connection, not application routes or files. Check the document root and entry file in project details.

## Why does Windows SmartScreen warn about the installer?

DevStackBox is not signed with a Windows Authenticode publisher certificate. SmartScreen may label the installer as from an **unknown publisher**. That is expected for open-source projects without a commercial code-signing cert.

The in-app updater uses a separate **minisign** signature on release assets. That proves update packages came from the project; it does **not** replace Windows publisher trust for the first install.

**What to do:** Download only from the [official GitHub release](https://github.com/DevStackBox/DevStackBox/releases/latest). Compare the installer SHA-256 with the hash on the [download page](https://www.devstackbox.com/download) (from GitHub) or in `CHANGELOG.md`. If SmartScreen still blocks you, choose **More info** → **Run anyway** after you trust the hash and source.
