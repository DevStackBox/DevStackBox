# Documentation screenshots

The approved manifest is screenshots.json. It contains 27 real v0.1.19 captures at native 1920 × 1032, taken on 26 October 2026 from the production executable with isolated demonstration profiles. The capture tool supplies JPEG; original bytes are retained without resizing or recompression.

The website publishes only approved manifest entries. Older files in this source directory are historical evidence and are not approved for the current website. Public copies of superseded captures are removed during this refresh.

## Capture and publishing rules

- Capture the running app after loading and transitions settle. Use a clean demo profile without private data or credentials.
- Never upscale, edit labels/status into an image, or describe JPEG converted to PNG as lossless.
- Record actual version, date, dimensions and scene. Check text at full size and on desktop/mobile website layouts.
- Keep the original available via the website enlarge/open-original controls.
- When updating the docs baseline, retake affected screens and update the manifest and references together. The website rejects captures below the declared width or from another documentation version.
- A screenshot is UI evidence, not proof of every workflow, security guarantee or published release availability.
