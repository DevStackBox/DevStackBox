## Capture and publishing rules

- Capture the actual app at native resolution, preferably at least 1920 pixels wide. PNG is preferred when the capture tool offers lossless output; preserve the original format otherwise.
- Never upscale a small image, convert JPEG to PNG and call it lossless, or edit version numbers, status badges, paths or health results into a capture.
- Verify text at 100% scale and at the website's displayed size. Keep the full-resolution original available through an enlarge action or direct link. Avoid further lossy optimization for UI text.
- Exclude credentials, personal account paths, logs, notifications and unrelated windows. Use a clean demonstration project for future project captures.
- Record the app version, date, native dimensions and scene. Captures of installed v0.1.17 do not show unreleased source changes.
- The website's LAUNCH-MEDIA.md tracks homepage assets and remaining retakes. Existing low-resolution project captures still need native-resolution replacements; enlargement cannot recover missing detail.
