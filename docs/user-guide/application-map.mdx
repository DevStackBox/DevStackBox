## Understand the scope

DevStackBox manages a local development stack. Connecting a project does not install its dependencies, migrate its database or prove it is healthy. A running process, a successful configuration parse and a successful HTTP response are different checks. A saved SQL backup needs a test restore before it can be relied on for recovery.

The database workspace is not a full SQL editor or a remote-server transfer tool. Use phpMyAdmin for table editing and advanced SQL. PHP's default selection applies to default websites and CLI; project pins apply to those websites. Automatic log maintenance only runs while the app is open and waits for service writers to stop.

The repository's documentation coverage check maps every application route and the shared flows above to maintained guides. That check detects missing guide mappings; it is not a substitute for runtime testing of every state or third-party application.
